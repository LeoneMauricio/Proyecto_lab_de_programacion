                Laboratorio - Proyecto final

1) desarrollar de forma individual una aplicación web de tipo catálogo con carrito usando únicamente, html, css o bootstrap y js. El rubro es dirección propia. ✅

2) El proyecto debe tener:
    - Un array de objetos con en un archivo propio (por ejemplo datos.js ) debe tener minimo 8 productos.
    - Las cards no deben ser escritas a mano en el html,se deben generar desde el array con map() y templates strings.✅

3) Eventos y delegacion:
    - Selección de elementos con el qwery selector, uso de delegacion de eventos, debe tener un solo listener en el contenedor con e.target.closest para los botones del card.✅

3) Para el carrito:
    - Incluir los botones para aumentar/disminuir cantidad y eliminar items.✅
    - Si el producto ya esta en el carrito, se debe incrementar no se duplica.✅
    - También debe tener un total y contador de items.✅

4) Persistencia con local storage.✅

5) Extras(no obligatorio):
    - Favoritos.
    - Notificaciones.
    - Modo oscuro.
    - Formulario.
